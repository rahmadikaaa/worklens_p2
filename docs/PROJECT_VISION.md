# Project Vision

## Confirmed

- **Application:** WorkLens. **Category:** Workforce & Automation Intelligence.
- **Objective:** analyze operational activities, identify automation opportunities, prioritize initiatives, and measure business impact.
- **Primary question:** "What should we automate, and how much impact can we achieve?"
- **Core capabilities:** operational data ingestion; workforce workload analysis; automation opportunity detection; automation prioritization; workload reduction calculation; automation impact measurement; AI-powered recommendations; operational intelligence reporting.
- **Context:** Kiroween 2026 — Skeleton Crew. WorkLens must be able to consume a future shared foundation. AutoRunner V2 is out of scope.
- **Principle:** correctness of data first. A verified source, traceability, and approved definitions precede any feature.

## Non-goals (current)

- AutoRunner V2.
- A generic framework beyond actual requirements.
- Any calculation lacking an approved definition.

## Unresolved

- Target users and their decisions (see `docs/DECISIONS/0003-open-questions.md`).
- Success measures for the hackathon demo.
- Resolved: the Kiroween planning brief supplied by the project owner is the authoritative architecture baseline (confirmed with the Phase 2 authorization).
